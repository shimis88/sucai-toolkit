# 图片无痕去水印（img-dewatermark）

在云电脑上用 CPU 跑，不用显卡、不联网、不花钱。
**RapidOCR 认字 → 只认「像水印」的字 → big-lama 补画**；Florence-2 只在确认有水印文字后，补找旁边的 logo。
默认**保守**：宁可漏掉一个，也不抹掉画面本来的东西（相机型号、招牌、远处的灯等）。

## 怎么用

```bash
img-dewatermark/run.sh <一张图或一个文件夹> [--out 输出文件夹]   # 或 sucai dewm
```

- 不写 `--out` 时，结果放在输入旁边的 `dewm_out/` 里。
- 输出文件名、格式、分辨率都跟原图一样（JPG 用 95 质量保存，PNG 无损，透明通道保留）。
- 真去了水印的图会多出一个 `xxx_mask.jpg`，红色就是被补画的地方。
- 没找到水印的图原样复制，并打印「跳过」和每处文字为什么保留。
- 从 X、小红书、抖音等平台抓的原图本来就没水印，`sucai batch` 会自动跳过，不用跑这个。
- 位置固定的小水印：直接 `run.sh 图 --no-detect --box x,y,w,h`，十几秒内出图。同一张图上平铺多处时，可先用 OpenCV `matchTemplate` 找出各处坐标，再 `--no-detect` 加多个 `--box`。

常用参数：

| 参数 | 作用 |
|---|---|
| `--box x,y,w,h` | 手动加一个要去掉的框（像素），可写多次，不受任何规则限制 |
| `--no-detect` | 不自动找，只用 `--box` 的框（每张 1~5 秒） |
| `--anywhere` | 不限边缘一圈，画面任何位置「像水印」的字都去 |
| `--loose` | 旧的宽松模式：四个角里的短文字和 logo 也去（会误伤画面自带的字，一般不用） |
| `--all-text` | 画面里所有文字都去掉（包括字幕），一般不用 |
| `--prompt 词` | 换掉补找 logo 时用的词，默认 `watermark` |
| `--dilate N` | 遮罩往外扩几像素，默认 5；有残边就调大 |
| `--max-mask 比例` | 自动遮罩合计超过全图这个比例就判为误检、保留原图，默认 0.05 |
| `-v` | 列出每个框为什么去、为什么留 |

## 怎么判断哪些是水印（默认）

任何一条不满足就**保留原样**：
1. 不太大（单框不超过全图 6%），也不太小（字高不到短边 0.4% 的不算，比如远处的灯）。
2. 不像底部居中的字幕。
3. 在画面边缘一圈（离边 15% 以内）。
4. 文字有「水印证据」：@账号、平台名（抖音/小红书/快手/微博/B站/视频号…）、「xx号：123」「ID：123」、网址、©、图库站名（视觉中国、shutterstock…）。相机型号（G12、Canon）、招牌、产品字样不算。
   文字框宽过全图 45% 的不算（海报顶上的「@全体党员 这些话要牢记」这类标题横幅）。
4b. 认定一处水印后，在它周围放大 2 倍再认一次字，挨着的其他行算同一组一起去（比如抖音 logo 旁的「抖音」两个字、微博 logo 旁的账号名）。
5. 没有文字的 logo（Florence-2「watermark」检测，`install.sh --full` 才装）只有紧挨着第 4 条的文字才去，比如抖音 logo + 抖音号。干净图不会跑这一步。精简安装没有 Florence-2，只按文字去，logo 图标靠第 7 条的外扩一起盖住。
6. 最后一道保险：自动遮罩合计超过全图 5%，整张保留原图。
7. 文字框左右各扩 1.2 个字高、上下各 0.25 个（盖住图标），再外扩 5 像素；big-lama 只裁附近一块补画，遮罩外的像素和原图完全一样。

## 速度（这台 8 核 CPU 实测）

- 没水印的图：每张约 **1 秒**（只跑 RapidOCR）。小红书 15 张 2000~4300px 原图合计 15.5 秒。
- 有水印的图：每张约 **8~12 秒**（多了 Florence-2 找 logo + 补画）；第一张多 3~5 秒加载模型。
- 只用 `--no-detect --box`：每张 1~5 秒。

## 效果和局限（实话）

- 角落/边缘的 @账号、平台 logo+号、网址：去得干净，遮罩外像素不变。
- 水印压在复杂物体上时，那一块会被补成合理的背景，被挡住的原细节补不回来。
- **画面中间、斜着的大号半透明水印**不处理（框太大，硬补会抹掉主体）；`--anywhere` 只放开位置，不放开大小。
- **没有任何文字的纯 logo 水印**、电视台台标默认不去（怕误伤画面里的 logo）；要去用 `--loose` 或 `--box`。
- 紧挨着水印的其他字也会一起去（比如人民日报海报底部「人民日报|微博」logo 和下面的微博水印连在一起，两个都去掉了）；被水印盖住一半的画面小物件也会被补掉。
- 画面边缘本来就有的、恰好带网址/@/平台名的字（比如店招上的「微信」「www.xxx.com」）会被当水印去掉。
- 很淡或很小的水印 OCR 可能认不出，看输出里的「保留」原因，必要时用 `--box`。

## 安装了什么

- 环境：仓库根目录 `.venv-ml`（Python 3.12，和人声分离共用 CPU 版 torch 2.5.1）。全部离线运行。
- `models/big-lama.pt`（197MB，LaMa 补画，Apache-2.0，安装时从 Sanster/models 官方 Release 下载并校验 sha256）
- RapidOCR 1.4.4（Apache-2.0，PP-OCRv4 中英文模型在 wheel 里）
- 可选 `--full`：`models/hf/` 里的 microsoft/Florence-2-large（1.5GB，MIT），transformers 必须 <4.50。
- 速度、版本见上文和根目录 `THIRD_PARTY_LICENSES.md`。

## 代码结构

- `run.sh`：入口
- `dewm/cli.py`：参数、读图存图、遮罩预览、最后一道保险
- `dewm/detect.py`：RapidOCR 认字；Florence-2 找「watermark」logo
- `dewm/select.py`：挑出哪些框算水印（上面的规则都在这里）
- `dewm/mask.py`：框变遮罩、外扩
- `dewm/inpaint.py`：big-lama 裁块补画、贴回
- `dewm/paths.py`：模型路径，强制离线
- 自测：根目录 `sucai selftest` 第 3 步（合成一张带 @账号 的图）
